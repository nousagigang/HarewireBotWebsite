🐛 Found a Bug?

HarewireBot is still under development, so bugs and unexpected behavior are possible.

When reporting an issue, it helps to include:

  • What you were trying to do
  • Which command or feature was involved
  • What you expected to happen
  • What actually happened
  • Any relevant error message or screenshot
🔒 Please protect your credentials.
Never include passwords, Discord bot tokens, API keys, registration secrets, or other private credentials in a bug report.

🔐 Security

If you've discovered a potential security vulnerability, please do not publicly disclose sensitive details.

Send security reports to:

security@your-domain.example

For security-related reports, please provide enough information to reproduce or understand the issue without including unnecessary sensitive information.
