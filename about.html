PROJECT ARCHIVE // HAREWIRE

The Harewire Bot Project

A Discord bot project that started in 2024, disappeared into uncertainty, and came back as something entirely new.

HarewireBot isn't actually the first Harewire.

The Harewire Bot Project began in 2024 with a simple Discord bot created for the Nousagi Gang. What started as a customizable server bot eventually became the foundation for a much bigger idea.

In 2026, that idea returned in a new form: HarewireBot — a Discord bot being built from scratch, without depending on a premium bot builder.

The implementation changed. The rabbit didn't.

2024

🐇 Harewire is born

The original Harewire Discord bot was created for the Nousagi Gang.

It was built using BotGhost, a platform that made it possible to create and customize a Discord bot without having to build the entire system from scratch.

Harewire quickly became part of the group's Discord experience and served as an experiment in what a customizable community bot could do.

THE NAME

Why "Harewire"?

The name came from the identity of the group itself.

Nousagi is Japanese for "wild rabbit." The word Hare naturally became part of the bot's identity.

The wire part came from the games the group played together — cyberpunk- inspired, text-based MMORPGs where connections, networks, and digital worlds were a big part of the experience.

Put them together:

Hare + Wire = Harewire.

2025

⚠️ The uncertain year

In 2025, BotGhost experienced an issue involving Discord that created uncertainty around the platform's future.

For a while, it seemed possible that the original Harewire might disappear with it.

Fortunately, BotGhost continued operating, and Harewire remained alive.

The experience did, however, raise an interesting question:

What if Harewire could be built independently?

2026

🚀 HarewireBot begins

In 2026, development began on a new Harewire implementation.

This time, the goal was different.

Instead of relying on a bot-building platform, HarewireBot would be developed independently, allowing complete control over its architecture, commands, permissions, infrastructure, and future features.

The project became an opportunity to learn how Discord bots actually work — from interactions and slash commands to serverless infrastructure and APIs.

IMPORTANT DISTINCTION

This isn't Harewire 2.0.

HarewireBot isn't intended to be a simple version upgrade of the original Harewire.

It is a new implementation inspired by the same idea and identity.

That's why the name became HarewireBot rather than "Harewire 2.0" or "Harewire V2."

The original Harewire has its own history. HarewireBot is the next chapter.

From customization to creation.

BotGhost made it possible to create the original Harewire without needing to build everything from scratch.

And that was valuable.

But eventually, curiosity took over.

Instead of asking "What can I configure?", the project could now ask:

"What can I build?"

HarewireBot is the answer to that question.

🛠️ HarewireBot Today

HarewireBot is currently an independently developed Discord bot running on Cloudflare Workers.

The project is being developed incrementally, with each milestone establishing another part of the bot's foundation.

As of v0.3.0, the command system is complete and development has moved into Phase 5 — Bot Features.

👩‍💻 About the Developer

HarewireBot is independently developed and maintained by K4LM3D.

The project began with a simple Discord bot created in 2024 for the Nousagi Gang. What started as a customizable community bot eventually became an opportunity to learn how to build and operate a Discord bot independently.

In 2026, the idea was rebuilt from the ground up as HarewireBot, using technologies such as TypeScript, Cloudflare Workers, Hono, and Discord's Interactions API.

HarewireBot is both a practical project and a learning journey — gradually growing from a simple experiment into something more capable, one phase and one release at a time.
