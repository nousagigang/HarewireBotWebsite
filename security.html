🔐 Security

Information about reporting potential security vulnerabilities in HarewireBot and its public infrastructure.

Reporting a Vulnerability

If you discover a potential security vulnerability in HarewireBot or its public infrastructure, please report it privately through:

SECURITY CONTACT kalmedkaliber@protonmail.com
⚠️ Please report vulnerabilities privately.
Please do not publicly disclose the vulnerability before it has been reviewed.

What to Include

When submitting a security report, please provide enough information to help understand and reproduce the issue.

  • Description of the vulnerability
  • Steps to reproduce
  • Potential impact
  • Relevant screenshots or logs, if applicable
  • Any suggested mitigation, if known
🔒 Never include credentials.
Please do not include passwords, API keys, Discord tokens, registration secrets, or other credentials in your report.

Recognition

HarewireBot does not currently offer monetary bug bounties.

However, we appreciate responsible security research and may recognize researchers who report valid vulnerabilities and assist with responsible disclosure.

With the researcher's permission, acknowledgments may appear on:

  • The HarewireBot website
  • The project's public repository
  • Future project documentation
ANONYMOUS REPORTING IS WELCOME

Researchers may choose to remain anonymous.
