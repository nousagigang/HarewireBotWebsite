# 🐇 HarewireBot Website

> The public development hub for HarewireBot — a Discord bot in the making, one phase, one command, and one release at a time.

This repository contains the static website for **HarewireBot**, a Discord bot currently under active development.

The website serves as the public-facing home for the project, providing a place to follow HarewireBot's development, progress, releases, roadmap, milestones, and development journey.

## 🖥️ About

HarewireBot started as an experiment to explore how a lightweight, serverless Discord bot could be built using **Cloudflare Workers** and Discord's slash command system.

While the bot itself is still under development, this website documents the journey as it happens.

The website uses a retro-inspired, CRT-style interface designed to make the experience feel less like a traditional project website and more like **booting up HarewireBot itself**.

## ✨ Features

- 🎮 Retro-inspired "Press Start" landing screen
- 🖥️ CRT / terminal-inspired visual design
- 🤖 Bot project overview
- 📈 Development progress tracking
- 🗺️ Project roadmap
- 📋 Release changelog
- 📦 Release history
- 📖 Development journal
- 📱 Responsive design for mobile and desktop
- ♿ Reduced-motion support
- ⚡ No build system required
- 🧩 Fully static website
