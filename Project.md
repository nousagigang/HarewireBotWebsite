### `index.html`

The main HarewireBot landing page.

It contains the interactive **Press Start** introduction followed by the project's:

* Overview
* Current capabilities
* Technology stack
* Development status
* Phase progress
* Upcoming phase
* Project navigation

### `style.css`

Contains the visual design and responsive layout, including:

* CRT scanlines
* Pixel-style typography
* Orange phosphor glow
* Retro terminal styling
* Responsive layouts
* Progress bars
* Navigation
* Cards and panels
* Animations

### `script.js`

Provides the website's interactive behavior:

* Press Start transition
* Keyboard support
* Mobile navigation
* Scroll-based content reveals
* Reduced-motion compatibility

## 🚀 Running Locally

This is a static website, so no build process is required. You can simply open `index.html` in a web browser.

Alternatively, serve the directory using any static web server. For example, use the command `python -m http.server` in your terminal. Then open `http://localhost:8000` in your browser.

## 🌐 Deployment

The website can be deployed to any platform capable of serving static files.

Examples include:

* Cloudflare Pages
* GitHub Pages
* Netlify
* Vercel
* Any traditional web server

The website does not require a backend.

# 🎨 Design Philosophy

The website's design is inspired by:

* Retro computer terminals
* CRT displays
* Classic video games
* Pixel interfaces
* Early computer interfaces
* Orange phosphor displays

The **Press Start** screen is intentional.

Rather than immediately presenting a conventional project homepage, visitors are invited to:

```text
<< PRESS START >>
```

Once started, the website transitions into the HarewireBot development hub.

The idea is simple:

> **You're not just visiting the website. You're booting up HarewireBot.**
