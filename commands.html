/say

Makes HarewireBot send a message provided by the user.

AVAILABLE
OPTION message — required
PERMISSION Manage Messages
USAGE /say message: Hello, world!
🔐 Permission protected
The command requires the Discord Manage Messages permission. HarewireBot also checks the user's permissions at runtime before executing the command.
