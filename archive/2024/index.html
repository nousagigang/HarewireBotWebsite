🐇 Harewire

The beginning of the Harewire Bot Project. Preserved from its original 2024 era.

Before there was HarewireBot, there was simply Harewire.

Created in 2024 for the Nousagi Gang, the original Harewire was a Discord bot built using BotGhost.

It was created as a customizable utility bot for the group's Discord community and became part of the games, conversations, and online spaces shared by the group.

This archive preserves documentation and other materials from that first generation of Harewire.

⚠️ ARCHIVED MATERIAL The materials in this section describe the original 2024 Harewire bot. They are preserved for historical reference and may no longer accurately describe the current HarewireBot project.

🕰️ A Little History

2024

Harewire is created

The original Harewire Discord bot is created for the Nousagi Gang using BotGhost.

2024

The first Harewire website

A simple website is created to document the bot and its commands.

2025

The Harewire story continues

Changes and uncertainty surrounding BotGhost lead to questions about Harewire's future. The original bot nevertheless continues to exist.

2026

HarewireBot begins

A new version of the idea begins: an independently developed Discord bot built with Cloudflare Workers.

🐇 From Harewire to HarewireBot

The original Harewire and the current HarewireBot are not the same implementation.

HarewireBot was created in 2026 as a new, independently developed Discord bot inspired by the original project.

The name was kept because the idea behind Harewire was worth continuing.

The archive exists to remember where the project came from while the current website documents where it is going.
