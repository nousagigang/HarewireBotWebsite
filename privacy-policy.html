HAREWIREBOT // PRIVACY

🔐 Privacy Policy

This Privacy Policy explains how HarewireBot and the HarewireBot website handle information.

LAST UPDATED: AUGUST 2026

HarewireBot is an independently developed Discord bot currently under active development. This policy reflects the project's current features and practices and may be updated as HarewireBot evolves.

1. About HarewireBot

HarewireBot is a Discord bot built using Cloudflare Workers and Discord's interaction system.

At its current stage, HarewireBot primarily processes Discord interactions in order to receive and respond to slash commands.

The bot is currently a development/pre-release project and is not intended to be considered a finished production service.

2. Information HarewireBot Processes

When you interact with HarewireBot through Discord, Discord provides information necessary for the interaction to be processed.

Depending on the interaction, this may include:

  • Discord user and account identifiers
  • Server and channel identifiers
  • Information about the command being used
  • Command options or values provided by the user
  • Permissions associated with the interaction
  • Other information included by Discord as part of the interaction

HarewireBot processes this information only as necessary to handle the requested interaction.

For example, when using:

/say message: Hello!

HarewireBot receives the command and the provided message so that it can generate the requested response.

3. Information HarewireBot Currently Stores

HarewireBot's current command system does not intentionally maintain a permanent database of user messages or Discord interactions.

Information received while processing an interaction may temporarily exist during request processing or appear in operational logs used for development, debugging, and troubleshooting.

🚧 Development status
HarewireBot is currently being developed and tested, so logging and data-handling practices may change as new features are introduced.

If persistent storage is introduced in the future, this Privacy Policy will be updated to describe the information stored, the purpose of storage, and applicable retention practices.

4. Website Information

The HarewireBot website may receive information that is normally transmitted when visiting a website, depending on the hosting and infrastructure services used.

This may include technical information such as:

  • IP address
  • Browser and device information
  • Date and time of access
  • Requested pages
  • Referring page or service

The website does not intentionally request sensitive personal information simply for browsing the site.

If analytics, cookies, contact forms, or other data-collecting functionality is introduced, the relevant information and purposes will be documented in this Privacy Policy.

5. Contact Information

If you contact HarewireBot by email or another provided contact method, the information you voluntarily provide may include:

  • Your name or username
  • Email address
  • Message contents
  • Other information you choose to provide

This information is used to respond to your inquiry, feedback, security report, or other request.

🔒 Protect your credentials.
Please do not send passwords, Discord bot tokens, API keys, registration secrets, or other credentials through ordinary contact channels.

6. Security Reports

Security vulnerabilities should be reported privately through the security contact provided on the Security page.

Information submitted as part of a security report may be used to:

  • Investigate the reported issue
  • Reproduce and verify the vulnerability
  • Communicate with the reporter
  • Develop and deploy a fix
  • Document the security issue when appropriate

HarewireBot does not currently offer monetary bug bounties.

Researchers who responsibly report valid security issues may be eligible for public acknowledgment, with their permission.

7. Third-Party Services

HarewireBot relies on third-party services to operate its current infrastructure.

  • Discord — provides the platform through which users interact with HarewireBot.
  • Cloudflare — provides the infrastructure used to run HarewireBot.

These services may independently process information according to their own privacy policies and terms.

HarewireBot does not control the privacy practices of third-party services.

8. How Information Is Used

Information processed by HarewireBot or voluntarily provided through the website may be used for purposes such as:

  • Providing and responding to bot commands
  • Operating and maintaining the project
  • Troubleshooting technical problems
  • Investigating security issues
  • Responding to inquiries
  • Improving HarewireBot
  • Protecting the security and integrity of the project

HarewireBot does not currently use Discord interaction data for advertising or sell personal information to third parties.

9. Data Retention

HarewireBot does not currently maintain a general-purpose database containing users' Discord messages or command interactions.

Information contained in temporary processing data or operational logs may be retained for as long as reasonably necessary for development, debugging, security, or operational purposes.

Contact and security-report information may be retained as reasonably necessary to respond to the request, investigate an issue, maintain project records, or comply with applicable obligations.

Retention practices may change as HarewireBot develops. Significant changes will be reflected in this Privacy Policy.

10. Data Security

Reasonable technical and organizational measures are used to protect information handled by HarewireBot and its website.

These measures may include:

  • Restricting access to private project infrastructure
  • Keeping credentials and secrets out of public source repositories
  • Using environment-based secrets for sensitive configuration
  • Using HTTPS for public website communications
  • Limiting access to information needed for development and operation

However, no online system can guarantee absolute security.

If a security vulnerability affecting personal information is discovered, HarewireBot will take reasonable steps to investigate and address it.

11. Your Privacy Rights

Depending on applicable law, you may have rights concerning personal information processed by HarewireBot.

These may include rights to:

  • Be informed about the processing of your personal information
  • Request access to personal information concerning you
  • Request correction of inaccurate or incomplete information
  • Object to certain processing
  • Request deletion, blocking, or restriction where applicable
  • Exercise other rights provided by applicable privacy laws

Under the Philippine Data Privacy Act of 2012, data subjects have recognized rights concerning their personal information, subject to applicable conditions and limitations.

To make a privacy-related request, contact us using the information provided on the Contact page.

12. Children's Privacy

HarewireBot is not specifically designed to collect personal information from children.

The project does not intentionally request sensitive personal information from users through its current features.

If you believe that personal information has been provided to HarewireBot or through the website inappropriately, please contact us .

HarewireBot is an actively developing project.

This Privacy Policy may be updated when:
